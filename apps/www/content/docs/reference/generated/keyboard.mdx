Aggregated by `scripts/build-reference.mts` from the `<KeyboardTable>` on every component page, so a key that is not documented on its component cannot appear here. Run `pnpm run generate`.

*Component* and *part* say where focus must be, *Key* is written as a keyboard prints it, such as <Kbd>Shift</Kbd> <Kbd>Tab</Kbd>, *Action* is the outcome, and *Notes* carries the exceptions. Browser and operating-system defaults are not listed. The focus contract lives in [Accessibility](../../foundations/accessibility.mdx), and this site's own <Kbd>Ctrl</Kbd> <Kbd>K</Kbd> search shortcut is not part of opsinjs.
