Generated by `scripts/build-reference.mts` from the `export` declarations under `lib/`, read textually so the page builds before anything compiles. Run `pnpm run generate`; to improve a row, improve the symbol's doc comment.

These are the site's own symbols. `lib/opsinjs.ts` is copied into a consumer's project with every component, and the clinical vocabulary there is the part that matters: `ClinicalStatus` is the union of the four status levels and `HealthCategory` the union of the categories, so mixing the two axes is a compile error rather than a review finding ([Two colour axes](../../health/two-colour-axes.mdx)). Nothing here installs from npm. Component props are on each component page. Generated modules under `lib/generated/` and names starting with an underscore are excluded.

### DataState

The state a data surface is in, named once so the surfaces converge on one vocabulary, though no component accepts it yet.

These are the five states the Data states foundation names, which are loading, error, empty, partial and stale, plus the resolved case where the value is real, current and simply rendered. No component accepts this type yet.
