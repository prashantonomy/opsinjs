Measured by `scripts/check-contrast.mts` from `tokens/accent.json`, read through `scripts/accent-plan.mts`, with the hand-written maths in `lib/color/apca.ts` and `lib/color/wcag.ts`, into `lib/generated/accent-contrast.json`. `pnpm run contrast` measures and `pnpm run contrast:verify` fails on a failing or moved pair. `scripts/build-tokens.mts` measures the same pairs before it writes a token and refuses one below its floor, so a failing accent never reaches `app/tokens.generated.css`. No figure here was typed by a person.

Normal and vibes are held to the system's floors. Stryk is held to enhanced floors: WCAG 2.2 AAA (7:1) and APCA Lc 85 for text, 4.5:1 and Lc 60 for boundaries and rings. An exempt pair is a bright fill whose edge carries the boundary instead, and the edge is measured in its place. [Accent](../../foundations/accent.mdx) explains the themes.
