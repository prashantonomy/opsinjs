The generated pages are written by scripts from the same sources the build ships, so a row cannot describe a token the build does not have. `pnpm run check` regenerates them and diffs the result, so a page that drifts from its source fails the build. To change a row, change the source. An edit between a page's generated markers is erased by the next `pnpm run generate`. A program should read the same lists from `/llms.txt`, the `.md` twin of each page, or `/r/index.json`.
