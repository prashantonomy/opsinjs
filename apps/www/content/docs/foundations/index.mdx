kind: foundation

Foundations decide once what a colour, a size, a corner or a state means, so every component gives the same answer. Each page states the rules a component follows, and each token family ends in a table generated from `tokens/*.json`. Change a value in [Theming](../theming.mdx), and see every token in one list in [Tokens](../reference/generated/tokens.mdx).

| [Typography](./typography.mdx) | The platform UI font, a type scale named for jobs, and the reader's own text size |
