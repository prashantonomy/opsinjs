## When to use it

<WhenToUse
  use={[
    "Content whose size and position are known in advance, arriving within roughly a second, where the alternative is the layout jumping when it lands.",

## Accessibility

Rendered, it shows no violation, target-size hit, missing focus-visible state or
reflow failure at 320px, and the audit changed nothing. On every commit
`pnpm run check:a11y` checks that no status colour can reach a skeleton, that every
colour is a theme role (`bg-placeholder-fill`, `border-placeholder-line`), and that no
type size is in `px`. `pnpm run contrast` measures the placeholder line clearing the
non-text floor against the page, a card and the muted ground in both themes.

**Argued from the source, not measured.**

- The root is `aria-hidden`, nothing is focusable or interactive, and it is
  `print:hidden`.
- No live region mounts, on purpose. A list of many skeletons should be announced once,
  not once per block, so the caller owns one `role="status"` message beside the region
  rather than inside it, as both examples show.
- The shimmer is declared inside a `prefers-reduced-motion: no-preference` query, so
  under reduce it never runs and the static tint remains.
- The shimmer runs two cycles, about 3.2 seconds, then stops on the static tint, so
  SC 2.2.2 does not engage. The appearance delay is never suppressed.
- There is no `forced-colors` or `prefers-contrast` override, because the decorative,
  `aria-hidden` root has no information an override would need to preserve.

**Residual items.** `pnpm run contrast` puts the placeholder line below Lc 45 against
its own fill in the dark theme, and the fill is published as advisory. No gate checks
the 200% and 1.3x layout claims, what a screen reader announces, the dark-theme
boundary on its own fill, or the text rhythm on a browser without the `lh` unit.

## Props interface

<PropsTable name="SkeletonProps" />

`Skeleton` is a server component: `appearAfterMs` is a CSS `animation-delay`,
not a timer, so the placeholder holds the layout before hydration. A `shape`
outside the four resolves to `text`. `lines` is clamped to 1 to 24. No part is
exported; style them through `data-slot`.
