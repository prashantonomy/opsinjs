```tsx

    {items.map((item) => (
      <li key={item.id}>{item.label}</li>
```

## Accessibility

The viewport holds a keyboard tab stop and takes an accessible name through `label` or
`labelledBy`. Reflow and target size pass, with no colour-axis, token, `px` or
colour-literal issue. The audit fixed one serious defect: the viewport was not a
reliable tab stop and had no name, so a screen reader met an unnamed stop. The
default demo and both examples now name their region, one by pointing `labelledBy`
at its on-screen heading.

**Residual items.**

- In the card example the rounded corners can partly clip the focus ring at the flush
  bottom edge, though the indicator stays perceivable.
- The thumb's contrast and the pairs below are not measured in source.

## Props interface

<PropsTable name="ScrollAreaProps" />

`maxHeight` gives the region something to overflow, so set it in a rem rather
than a pixel count. Given neither it nor a height class, the region grows to fit
and a development warning names the omission. `className` is the one route by
which colour reaches the region, and the two-colour-axes rule applies in full.
