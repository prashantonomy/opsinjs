```tsx

```

```tsx
<Table
  caption="Example figures by period, and not a real record"
  columns={[
    { key: "period", header: "Period" },
    { key: "count", header: "Count", numeric: true },
  ]}
  rows={[
    { period: "Period one", count: "12" },
    { period: "Period two", count: "1,000" },
  ]}
/>
```

## Content guidelines

Write a caption naming the rows and the columns, so the table stands on its
own. Where a heading already names the data, keep the caption and set
`captionHidden`.

<DoDont>
  <DoDont.Do>
    **"Weekly figures for the example account, in the example unit"** names the rows and what the columns measure.
  </DoDont.Do>
  <DoDont.Dont>
    **"Table"**, or an empty caption, leaves a grid of numbers counting nothing.
  </DoDont.Dont>
</DoDont>

## Accessibility

**Checked by `pnpm run check:a11y` on every commit.** Every colour is a neutral
role token, no type size is in `px`, and no banned word or clinical threshold
appears.

**Argued from the source, not measured.**

- `caption` is a required `string`, and `captionHidden` uses sr-only rather
  than removing it.
- Every header is `scope="col"`, and the first cell of a row is `scope="row"`
  while `rowHeader` is on.
- The container is `overflow-x-auto` and focusable, so a wide table scrolls in
  its own box within reach of a keyboard.
- No colour prop, no `data-status`, no `data-category` and no transition.

**Not checked by any gate.** The measured contrast of the header ink, the
caption ink and the hairlines, the screen reader read, and 200% text.

## API reference

<PropsTable name="TableProps" />

`caption` is a required `string`, because there is no honest caption this
component can invent. `rowHeader` defaults to true, so the first cell of each
row is a `th`. There is no `onSort`, no `selectedRows` and no `virtualized`.
