## Clinical meaning

**Asserts.** One specific permission is being asked for, and the reader has been told
what is collected, what it is for, who sees it and how long it is kept.

**Never read as.** A condition of using the product, unless it genuinely is one and the
sheet says so, and never as permanent, because the sheet says where to withdraw. See
[Consent and privacy](../health/consent-and-privacy.mdx).

**Colour axis.** Neither. No element carries `data-status` or `data-category`.
See [Health](../health/index.mdx).

**Thresholds.** None. The sheet displays no reading. Every consent string
arrives as a prop, because the wording is the product's legal statement
([Safety review](../health/safety-review.mdx)).

**Closing is not deciding.** Only the two controls call `onDecision`. Escape, scrim,
drag and header Close call nothing, so *did not answer* is the absence of a call, never
a stored `false`.

<SafetyCallout severity="urgent" evidence="opinion">
No pre-ticked boxes, no default-on switches, no *agree* that is also *continue*, and no
sheet that cannot be closed without deciding.
</SafetyCallout>

## Accessibility

`heading` is the dialog's accessible name and `purpose` its description, and focus lands
on the sheet. The two decisions are one grid, one `Button` variant at one size, decline
first and never stacked, and the copy carries every meaning so nothing rides on colour.
The details trigger is a real button with `aria-expanded` and `aria-controls`. The
audit's one fix put its focus ring on the decision buttons' `--opsin-border-focus`
token, so a theme that thickens the ring reaches it too. A ring was already visible, so
no gap closed. `pnpm run check:a11y` holds every commit to no `px` size, raw colour,
banned word or element resolving a category or status property.

**Residual items.**

- With `heading` omitted the sheet refuses to ask and the dialog has no accessible name.
  The component warns in development, so this is invalid usage, not a supported state.
- The open sheet could not be exercised rendered, so its verdicts rest on source.
- Focus trap, focus return, dismissal and the swipe close alternative belong to
  [Sheet](./sheet.mdx) and are verified there.

## Props interface

<PropsTable name="ConsentSheetProps" />

```ts
interface ConsentScope { collected: string; sharedWith: string; retention: string }
interface ConsentDetails { label: string; content: ReactNode }
interface ConsentDecision {
  granted: boolean; at: string; consentId: string; textVersion: string; scope: ConsentScope
}
```

`ConsentSheetProps` extends [SheetProps](./sheet.mdx#props-interface) with `title`,
`children` and `footer` removed, because `heading` is the title. A whitespace-only string
counts as missing. There is no `purposes`, `defaultGranted`, `required`, `hideDecline`,
`acceptVariant` or `declineVariant`.
