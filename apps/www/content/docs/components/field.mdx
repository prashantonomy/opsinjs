```tsx
import { Field } from "@/components/ui/field"
```

```tsx
<Field label="Example measurement" hint="For example, 14">
  <Field.Control name="example-measurement" inputMode="decimal" autoComplete="off" />
</Field>
```

## Accessibility

A native `label` points at a generated id, `aria-describedby` survives unmount,
`aria-invalid` sits on the control, and the invalid state is a glyph and a left rule,
never colour. The audit gave the error a live region, so it is announced on submit
while focus is on Save, where it was silent before. Rendered, it shows no axe
violation and no reflow at 320px, targets meet `--opsin-target-minimum`, and focus is
visible. `pnpm run check:a11y` guards role tokens and non-`px` sizes.

**Residual items.**

- The required and optional word is English only and untranslatable by prop.
- The focus ring lives in `product.css`, so a `shadcn add` copy without it shows no
  ring until you add one.
- The invalid shadow drops under forced colours and print, where the glyph, words and
  rule still carry the state.
