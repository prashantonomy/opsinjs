## Accessibility

A card takes no role or name unless it is a link. It carries the page's heading level
in a title slot that resets font and margin, floors a link target at
`--opsin-target-minimum`, and keeps its edge under greyscale, `forced-colors` and print.
The resting chevron is `aria-hidden`, backed by the title underline and anchor as
redundant cues. There is no axe violation and no 320px reflow failure, and
`pnpm run check:a11y` confirms on every commit that every colour is a role token, no
type size is in `px`, and no banned word appears. The audit moved the link card's
`focus-visible` ring from a hardcoded 2px outline to `--opsin-border-focus` and
`--opsin-border-focus-offset`, so a product raising those gets a wider ring here, and
the default stays 2px.

**Residual items.** A link card is one anchor, so its accessible name is all its text
at once. Weigh that verbosity before putting `href` on a long card.

## Props interface

<PropsTable name="CardProps" />

`rung` defaults to `card`, not `raised`, and never goes above `raised`: a
translucent rung warns in development and renders. `render` takes the
router's link element, not a function, and does nothing without `href`. There is
no `status`, `variant`, `color` or `category`.
