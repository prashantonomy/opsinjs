## What this name refers to

An on-or-off control that takes effect immediately.

## Why it is not on the roster

Delegated to Base UI. A switch must never be used for consent — consent is a decision with a record, not a setting.

## What to use instead

Use [ConsentSheet](consent-sheet.mdx) or [Checkbox](checkbox.mdx) instead.
