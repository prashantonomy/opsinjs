## Accessibility

**Checked by `pnpm run check:a11y` on every commit.** Every colour is a role
token, no type size is in `px`, and no shipped string uses a banned word.

**Argued from the source, not measured.**

- A modal sheet takes the dialog role, is named by `Sheet.Title` and traps
  focus. The page behind is `aria-hidden`, not `inert`.
- Every gesture has a control: the close button for drag-to-dismiss, the
  grabber for drag-between-detents.
- The footer sits outside the scrolling region and inside the keyboard inset,
  so the primary action is never covered.
- `prefers-reduced-motion` removes the distance, not the transition. It
  crossfades in place, and the drag still works.

**Not checked by any gate.** The 44 by 44 targets, close and grabber contrast,
and the grabber's clipped focus ring. Nor software keyboards, iOS scroll
chaining, `modal={false}`, `forced-colors` or `prefers-contrast`.
