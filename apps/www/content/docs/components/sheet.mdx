## Accessibility

The rendered pass found no axe, target-size, focus-ring or reflow failure at 320px, and
nothing was changed. A modal sheet takes the dialog role, named by `Sheet.Title`, and
traps focus, with the page behind `aria-hidden`, not `inert`. Every gesture has a
control: close for drag-to-dismiss, grabber for drag-between-detents. The footer sits
outside the scrolling region and inside the keyboard inset, keeping the primary action
visible. Under `prefers-reduced-motion` the sheet crossfades in place, and the drag
still works.

**Residual items.** Focus rings use a negative outline offset to stay visible inside the
clipped popup, meeting 2.4.7 and 1.4.11. No live region announces the new height. The
grabber's accessible name updates to name the next action instead. `modal={false}` pins
the sheet to the bottom while the page behind stays focusable, an unchecked obscured-focus
shape. Default and demo stay modal.
