## Clinical meaning

**Asserts.** Exactly one thing: these are the tones the bar beside it draws, and this is what each one means. It says nothing about any reading, cause or next step.

**Never read as.** A scale, a diagnosis or a verdict on the reader. "Needs attention" names a tone a product may assign, not the reader's own result. "Normal" and "abnormal" are banned from every row, and [Reference ranges and normal](../health/reference-ranges.mdx) carries the list.

**Colour axis.** The status axis and the neutral reference range band, nothing else. No swatch is category tinted and no element carries `data-category`, because [The two colour axes](../health/two-colour-axes.mdx) never meet on one key. Every status row draws fill, distinct glyph and word together, so the level survives greyscale.

**Thresholds.** The consuming product owns every word, range and level. RangeLegend ships no band names; the words arrive as props and the swatch colours are all it supplies.

## Content guidelines

Write each label in the reader's words, in the product's plain phrasing rather than a clinical register. The description is a short second line saying who set the range or what the tone means. Keep the neutral band's word about the range, never about the reader.

<DoDont>
  <DoDont.Do>
    **"The usual range" with a neutral swatch, then "Worth watching" with its own word, glyph and colour.**
  </DoDont.Do>
  <DoDont.Dont>
    **"Normal" with a green swatch and "Abnormal" with a red one.** A verdict on the person, carried by colour.
  </DoDont.Dont>
</DoDont>

## Accessibility

**Checked by `pnpm run check:a11y` on every commit.**

- A status row reads its glyph from `CLINICAL_STATUS_META` and prints the word, so colour never carries alone.
- No element carries both `data-category` and `data-status`; this file writes no category colour.
- No threshold is shipped and no raw colour literal appears.

**Argued from the source, not measured.**

- Each swatch and glyph carries `aria-hidden`, so a screen reader meets the labels and skips the decoration.
- Nothing takes focus, answers a key or animates, so `prefers-reduced-motion` has no state to reduce.
- At 200% text the swatches hold their size while the words wrap, and no ellipsis is set.
- Under `forced-colors: active` a status fill is stripped and the swatch keeps a `CanvasText` outline.

**Not checked by any gate.** Every contrast pair against the host ground, how the swatch list reads to a screen reader user, and what forced colours draws.

## API reference

<PropsTable name="RangeLegendProps" />

`tone` is typed to the four `ClinicalStatus` levels in [Clinical status semantics](../health/clinical-status-semantics.mdx). A value outside the four is refused with a development warning and the row falls back to the neutral band. An empty `bands` array renders nothing and warns in development.
