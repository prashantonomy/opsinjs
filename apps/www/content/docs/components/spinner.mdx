## Accessibility

The root carries a required `aria-label` plus a visually hidden text twin, and
the SVG ring is `aria-hidden`, so the decorative motion stays out of the
accessibility tree. Sizing is em based throughout with no `px` type step, and
the ring draws only in `currentColor`, with no status colour or category colour
of its own. Axe, target-size and 320px reflow checks were clean, and nothing
needed changing.

**Residual items.**

- The ring takes whatever ink colour the caller's context supplies rather than
  a colour the component sets itself, so its contrast against either theme's
  surfaces cannot be verified or hardened from source. That gap belongs to the
  report below.
- The missing-label warning is development only, so it does not stop a
  production caller passing an empty or whitespace `label`. `divider` and
  `segmented-control` follow the same convention.

## Props interface

<PropsTable name="SpinnerProps" />

`label` is required and has no default, because a guessed name would describe the
wrong wait. `size` defaults to `md` and chooses visual weight only. There is no
colour prop: colour reaches the ring only through `className`, and the
two-colour-axes rule applies to that class in full.
