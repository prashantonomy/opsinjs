```tsx

  open={open}
  onOpenChange={setOpen}
  title="Delete this reading?"
  description="It will be removed from your history and from any trends it appears in."
  actions={
    <>
      <Button variant="destructive" onClick={remove}>Delete reading</Button>
      <Button variant="primary" onClick={() => setOpen(false)}>Keep it</Button>
    </>
  }
/>
```

## Content guidelines

The title asks the question. The description says what each answer does, and on an
alert dialog why an answer is required. Labels are verbs naming the outcome, never
*OK* and *Cancel*, and never a judgement about the reader.

<DoDont>
  <DoDont.Do>
    **"Delete this reading? It will be removed from your history. [Delete reading]
    [Keep it]"** Question, consequence, two verbs.
  </DoDont.Do>
  <DoDont.Dont>
    **"Are you sure? [OK] [Cancel]"** Sure about what, and which button does which?
  </DoDont.Dont>
</DoDont>

## Accessibility

**Checked by `pnpm run check:a11y` on every commit.** Every colour is a role
token, no type size is in `px`, and no banned word appears.

**Argued from the source, not measured.**

- `severity="alert"` swaps in Base UI's alert-dialog root, so the role and the
  refusal to dismiss arrive together.
- Named by its title and described by its description. A blank description renders
  nothing.
- Focus moves in on open, is trapped, and returns on close to whatever had it.
- The page behind is `aria-hidden`, not `inert`, so programmatic focus from behind
  can still take it.

**Not checked by any gate.** Contrast of the close control's hover fill and the
focus ring over the scrim. The 48px floor on the actions row while open.
`forced-colors` under a Windows theme. No capture has seen the dialog open, because
the panel portals outside `#opsin-view-root`.

## API reference

<PropsTable name="DialogProps" />

`actions` and `closeLabel` are not in the specification. `closeLabel` defaults to
the English word *Close* and is ignored on an alert dialog. `onOpenChange` is not
called when Escape is refused. `sheetBelow` is not a prop: the dialog never becomes
a Sheet.

## Related

- [Sheet](./sheet.mdx) is a place the reader chose to go and may leave, which Dialog never becomes.
- [AlertBanner](./alert-banner.mdx) announces without blocking, for a reader who can carry on.
- [ConsentSheet](./consent-sheet.mdx) is a request with a consent contract and a recorded decision.
