## Accessibility

Confirmed: a real `nav` landmark named by `label`, and icons `aria-hidden` with the
label as the accessible name. The current destination carries `aria-current="page"`,
a heavier label and a top indicator, so no cue rides on colour. Every target is
floored at the 44pt minimum in rem. Axe, target-size, focus and 320px reflow checks
were clean, and the audit changed nothing.

**Residual items.**

- The colour and opacity fades carry no `prefers-reduced-motion` guard, which still
  meets AA because that guard is an AAA item.
- A `forced-colors` repaint may flatten the indicator bar, but `font-weight` and
  `aria-current` keep the current state legible.
- A bottom-fixed bar can obscure focused content, but this component owns no
  position, so SC 2.4.11 is the product's concern.
- Contrast for the current treatment on the overlay material is still unmeasured.
  See the report below.

## Props interface

<PropsTable name="TabBarProps" />

`value` makes this controlled, with no internal selection state, and a `value`
matching no item renders nothing current and warns in development.
`onValueChange` is optional, because a bar of links can leave navigation to the
`href`. `label` is required: an unnamed navigation landmark is a defect.
