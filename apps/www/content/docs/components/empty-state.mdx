```tsx

  reason="nothing-yet"

  action={{ label: "Add a reading", href: "/readings/new" }}

  compares it against.
</EmptyState>
```

## Accessibility

Neither colour axis is used, so nothing can mix. `titleLevel` renders a real `h2` to
`h6`, default `2`, so check it against the outline. The `could-not-load` flag carries
its meaning in a word beside an `aria-hidden` icon, not colour, and the `href` action is
an anchor floored at `var(--opsin-target-minimum, 2.75rem)` on both axes. The default
preview renders clean on `/view`, and the audit changed nothing.

**Residual items.**

- No live region mounts, by design. On a stateless, read-only render one could only
  mis-fire, since it announces only changes made after first paint. The announcement
  belongs to whatever region changed, which the caller owns, as the filter example shows.
- The three example files were audited from source alone.
- Contrast against the card surface is unmeasured, and the report below carries it.

## Props interface

<PropsTable name="EmptyStateProps" />

`reason` and `title` are required. There is no exported `EmptyReason` type, so
name the union `EmptyStateProps["reason"]`. A blank `title`, a body with no
text or only a number, and an action with nothing to do each render a fallback and
warn once. A `secondary` with no `action` also warns.
