# @opsinjs/react

## 0.1.0

### Minor Changes

- The first release of @opsinjs/react: the 60 opsinjs components, the shared substrate (`cn`, the unit table, error codes, the clinical vocabulary and the shared types), a precompiled stylesheet (`@opsinjs/react/styles.css`), a Tailwind CSS v4 entry (`@opsinjs/react/tailwind.css`) and the opt-in element rules (`@opsinjs/react/base.css`). Each component is also importable on its own as `@opsinjs/react/<id>`.

  opsinjs is at 0.x. The API may change in any release, and no component has had an independent accessibility review or a clinical review.
